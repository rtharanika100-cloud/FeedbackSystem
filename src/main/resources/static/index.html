ResolveFlow User Guide & Instructions

Complete guide on how to navigate, submit feedback, and manage escalations.

1

Getting Started & Roles

  • Register / Login: Click Login / Sign Up to create an account or switch user roles.
  • Customer Role: Used by end users to submit complaints, feature requests, or billing queries.
  • Agent Role: Used by support representatives to inspect tickets, write resolution logs, and resolve issues.
  • Supervisor / Admin: Used to manage agent assignments, prioritize ticket queues, and track audit trails.
2

Submitting & Tracking Feedback

  • Fill Out Form: Enter Subject, Category (Technical, Billing, Product, etc.), and Priority level.
  • Submit: Click Submit Feedback. Your request enters the system queue immediately.
  • Track Status: Monitor your ticket under Your Submitted Tickets. View real-time assigned staff and status.
  • Close or Reopen: Confirm resolution when resolved, or click Reopen Ticket if issue persists.
3

Staff Escalation & Workspace

  • Queue Filtering: Filter active tickets by Status (Created, Under Review, Assigned, Investigating, Resolved).
  • Agent Assignment: Assign tickets to specific support agents (e.g. Agent Smith, Billing Support).
  • Transition Status: Update status as work progresses. Every status change logs an immutable audit trail.
  • Internal Log Notes: Write internal progress notes to maintain a full history.
4

System Connection & Ports

  • Server Port: Backend runs on http://localhost:3000.
  • Authentication: Uses JWT Token stored securely in browser session.
  • REST API: Direct endpoints at /api/auth and /api/feedback.
